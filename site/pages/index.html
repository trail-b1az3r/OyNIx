OyNIx {{version}} for Linux

A browser that keeps to itself.

OyNIx is a desktop web browser written in Rust and drawn with Vulkan. Trackers and ads are stopped before they load, nothing about you is sent anywhere, and your Chrome and Firefox extensions come with you.

A quick tour

Everything is one click from the page.

There’s a single toolbar, and every button on it opens something you’ll use. Point at a number to see what it does.

{{shot:article.webp|OyNIx showing a Wikipedia article, with the toolbar along the top.}}
  1. Sidebar

    Bookmarks, Reading List, History and Claude, beside whatever you’re reading. Vertical tabs live here too, if you prefer them.

  2. Address field

    Shows the site, not a wall of parameters. Type goo and it completes to google.com, with the tracking tags already gone.

  3. Reader View

    Appears on pages with an article. It keeps the text and pictures and drops the rest. CtrlShiftR

  4. This site’s report

    How many trackers this page tried to load, which companies they belong to, and a switch to let the site through.

  5. All tabs

    A grid of live previews you can search by title or address. CtrlShift\

  6. The page itself

    Rendered by Chromium’s engine, so sites behave as they do in Chrome. In dark mode it follows your theme, even when the site has no dark theme of its own.

Privacy

Blocked before the request is made.

OyNIx checks every request against EasyList, EasyPrivacy, uBlock’s own filters and Peter Lowe’s list before it leaves your computer. Cookie banners, newsletter pop-ups and social widgets can go too, from lists you switch on.

The Privacy Report shows the companies that turned up on the most sites you visited. It’s worked out on your computer and stays there: OyNIx has no telemetry, no crash reporter and no account.

Appearance

Dark mode that reaches the page.

Most browsers turn dark around the page and leave the page alone. In OyNIx, a site with its own dark theme gets asked for it, and a site without one is darkened for you. If a site looks wrong that way, you can switch it off for that site only.

The interface follows Material 3: colours come from one accent you choose, controls change shape when you press them, and nothing is grey for the sake of it.

Extensions

Bring yours. Read ours.

Chrome and Firefox extensions install from a file, a folder or straight from addons.mozilla.org, where OyNIx adds its own Add to OyNIx button. Manifest V2 and V3 both work.

OyNIx extensions are smaller: a TypeScript file, a stylesheet and a few lines of JSON, with an optional panel of their own in the toolbar. The ones in the Extension Gallery are short enough that each page shows you the whole program before you install it.

Claude for OyNIx

Ask Claude to do the clicking.

Connect OyNIx to Claude Desktop or Claude Code, and Claude can open pages, read them, fill in forms and move between tabs. It uses real mouse and keyboard input, so sites respond as they would to you.

It asks before touching each site, can never see private windows or the sites you block, and shows a Stop button for as long as it’s working. It’s off until you turn it on.

Linux

Made on Linux, for Linux.

  • Draws with Vulkan 1.2 or 1.3, and falls back to OpenGL ES on older graphics.
  • Runs on Wayland or X11. On Hyprland, settings can open in a floating window.
  • WebUSB for flashing boards and talking to hardware, with a device picker and per-site access.
  • Separate profiles that run as separate apps, each with its own cookies and extensions.
  • Packages for apt and pacman that carry their own Qt, so nothing on your system changes.

The small things

You’ll find these on the first day.

Tabs that sleep

Tabs you haven’t looked at in a while are unloaded and quietly reload when you return. A restored session loads only the tab you’re looking at.

!bangs

Type !w otters to search Wikipedia, !gh for GitHub, !mdn for the web docs. Twenty-five are built in.

Three tab layouts

A tab bar under the toolbar, tabs inside the toolbar, or a vertical list in the sidebar.

Focus Mode

Hides everything except the page. Move the pointer to the top edge to get the toolbar back. CtrlShiftF

History that keeps up

Single-page apps that change the address without reloading are recorded too. Right-click Back to see where you’ve been in a tab.

Readable error pages

“Can’t find example.con” with a button to search for it, rather than a code to look up.

Reading List

Save a page to read later with CtrlShiftD. Unread pages wait on the Start Page.

Per-site settings

Zoom, JavaScript, pop-ups, blocking and dark mode, remembered for each site.

User scripts and styles

Drop .user.js and .user.css files in a folder; Greasemonkey headers are understood.

Private windows

Nothing from them is written to disk, and extensions and Claude can’t see them.

Clean addresses

Addresses you type lose their utm_ and fbclid tags on the way.

Import your bookmarks

From any browser’s HTML export, and back out again.

Download

OyNIx {{version}}

Packages for 64-bit Intel and AMD PCs. Each one includes its own copy of Qt, so it installs without touching your system’s libraries.

# download oynix_{{version}}_amd64.deb from the release page, then:
sudo apt install ./oynix_{{version}}_amd64.deb
# download oynix-{{version}}-1-x86_64.pkg.tar.zst from the release page, then:
sudo pacman -U oynix-{{version}}-1-x86_64.pkg.tar.zst
git clone {{repo}}.git && cd OyNIx
./scripts/deps-ubuntu.sh      # system libraries, Rust and Qt 6.12
cargo build --release
./scripts/install.sh          # into ~/.local, with a desktop entry
