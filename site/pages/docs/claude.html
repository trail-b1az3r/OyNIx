Turn it on

Claude for OyNIx is off until you enable it in Settings › Extensions › Claude for OyNIx. There are two ways to use it, and you can use both.

With Claude Desktop or Claude Code

This uses your Claude subscription. OyNIx includes an MCP server, which Claude starts when it needs the browser. For Claude Code, run once:

claude mcp add oynix -- oynix --mcp

For Claude Desktop, add this to claude_desktop_config.json and restart it:

{ "mcpServers": { "oynix": { "command": "/usr/bin/oynix", "args": ["--mcp"] } } }

The Setup page in OyNIx’s Claude panel shows both with the right path and profile for your install. oynix --mcp talks to the running browser over a socket only your user can open, and starts OyNIx if it isn’t running. OyNIx never sees your Claude login.

With the Claude panel

The sidebar’s Claude panel chats with Claude directly, using an API key from the Claude Console. Paste it in the panel’s Setup page; it’s stored in your profile folder, readable only by you. Usage is billed to that API account.

What Claude can do

Open, switch and close tabs; navigate; read a page as an outline of its elements; find text and elements; take screenshots; click, hover, type, press keys and scroll; fill in forms; wait for something to appear; read the console and network log; search your history and bookmarks. Clicks and typing are real input events, so pages react exactly as they would to you.

Limits

  • Ask per site. The first time Claude touches a site, OyNIx asks: allow for this task, always allow, or don’t allow. Unanswered requests are refused after two minutes.
  • Blocked sites are never available to Claude. Put your bank and email here.
  • Visible while working. The tab glows and a Claude is working · Stop chip appears. Stop refuses every further action until you resume.
  • Private windows are invisible to Claude.
  • Careful by instruction. Claude is told to treat page content as untrusted and to ask you before buying, sending, deleting or entering passwords.
  • Activity log. Every action is listed in the panel.

Web pages can contain text written to mislead an AI. Watch what Claude does on sites you don’t trust, and keep anything sensitive on the blocked list.
