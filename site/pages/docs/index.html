Install

Download the package for your distribution from the latest release and install it with your package manager. Both packages put OyNIx in /usr/lib/oynix with its own copy of Qt, so they don’t depend on, or change, the Qt on your system.

# Debian, Ubuntu, Linux Mint
sudo apt install ./oynix_{{version}}_amd64.deb

# Arch, Manjaro, EndeavourOS
sudo pacman -U oynix-{{version}}-1-x86_64.pkg.tar.zst

Each release also has a SHA256SUMS file. Put it next to the download and run sha256sum -c SHA256SUMS --ignore-missing to check the file arrived intact.

To build it yourself instead, see Building from source.

Updates

OyNIx updates itself. Once a day it checks for a new release; when there is one, it downloads the package in the background, checks it against the release’s published SHA-256, and offers to install it. Installing goes through your package manager (apt or pacman) and asks for your password, then Restart brings your tabs back in the new version.

Settings › About › Updates shows where things stand, the release notes, and a Check Now button. You can turn off the daily check or the background download there, or choose the beta channel to get pre-releases too. If you built OyNIx from source, it tells you about new versions but leaves updating to you.

The password prompt comes from a polkit agent. Full desktops run one already; on a bare Hyprland or Sway setup, start one (for example exec-once = systemctl --user start hyprpolkitagent), or install updates from a terminal with the command OyNIx shows.

First run

OyNIx opens on the Start Page with a few favourites to get you going; hover a tile and press the small × to remove it. Content blocking is already on. The filter lists download in the background during the first minute, and the Privacy Report on the Start Page starts counting as soon as they arrive.

Nothing else needs setting up. If you want to look around, Settings is Ctrl,, and it opens in a tab.

Bring your bookmarks

Export bookmarks from your old browser as an HTML file (every major browser can), then choose Settings › General › Import Bookmarks. Export Bookmarks writes the same format back out.

Make OyNIx your default browser

Settings › General › Default Browser registers OyNIx with your desktop, so links from mail, chat and terminal apps open in it. Under the hood this is xdg-settings set default-web-browser oynix.desktop, which you can also run yourself.

Profiles

A profile is a separate browser: its own history, cookies, extensions and settings. Start one with oynix --profile work; it’s created the first time. Each profile runs as its own app, so it gets its own window group and taskbar entry. Settings › Profiles lists them and opens any of them.

{{shape:cookie9:mask}}

A private window (CtrlShiftN) is different: it forgets everything when it closes. Use a profile when you want to keep two lives apart, and a private window when you want to keep nothing.
