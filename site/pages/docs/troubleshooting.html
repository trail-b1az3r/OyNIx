Before you start

Check the installed version in Settings › About. If a problem started after an update, note the previous and current versions and whether it happens in a fresh profile. Keep the exact error text; it is more useful than a screenshot of only the window.

Installation problems

APT reports a dependency or package error

Make sure you downloaded the Debian package (.deb) for the current release and install the local file rather than opening it as an archive:

sudo apt install ./oynix_VERSION_amd64.deb

If APT reports missing dependencies, let it resolve them with the command above. Do not rename an Arch package to .deb or vice versa.

Pacman refuses the package

Use the Arch package (.pkg.tar.zst) and install it with:

sudo pacman -U ./oynix-VERSION-1-x86_64.pkg.tar.zst

If the package is from the AUR, update it with your AUR helper rather than installing a downloaded binary over it.

OyNIx does not start

  • Run oynix from a terminal and read the first error printed there.
  • Check that the installed package matches your CPU architecture and distribution.
  • If the normal profile is damaged, try a temporary profile with oynix --profile troubleshooting. This creates a separate profile and does not replace your existing data.
  • If a profile works but the default one does not, disable recently installed extensions or test with a copy of the profile before changing or deleting data.

Graphics and rendering

OyNIx selects a graphics backend based on the display session and available driver. You can inspect the selected Vulkan device with oynix --gpu-info. To test another backend for one launch, use:

oynix --gpu vulkan
oynix --gpu gles
oynix --gpu opengl
oynix --gpu software

On Wayland, OpenGL ES is the normal interface backend; on X11, OyNIx may use Vulkan when supported. If the interface is blank, flickers or freezes, try another backend and compare. See Graphics for the reason behind the defaults.

Website compatibility

  • Try reloading the page and temporarily disabling the site’s extensions.
  • Open the shield in the toolbar and temporarily turn off blocking for the affected site if content is missing.
  • Check per-site JavaScript, pop-up and dark-mode settings under Settings › Websites.
  • Use a private window to check whether stored cookies or site data are involved. Extensions do not run in private windows.

Extensions

If an extension does not install, confirm that it is a supported Chrome/Firefox package or an OyNIx extension with the required files. For a power extension, its signature must validate against a trusted key. Review the extension’s requested permissions and try disabling it before removing it.

For development, use Settings › Extensions › Developer mode and consult Build an extension and Power extensions.

WebUSB permission denied

On Linux, your user may not have permission to open a particular USB device. Find the vendor and product IDs with lsusb, then follow the udev rule example in WebUSB. Reload the udev rules and reconnect the device.

Updates do not install

  • For APT or pacman installs, confirm the package manager is available and that your desktop session has a polkit authentication agent.
  • For a bare Hyprland or Sway session, start a polkit agent such as hyprpolkitagent.
  • For oynix-bin from the AUR, update with yay -Syu; OyNIx intentionally leaves AUR package installation to the AUR helper.
  • For source builds, rebuild from the latest source instead of expecting the package updater to replace your custom build.

Collect useful diagnostics

When reporting a problem, include:

  • OyNIx version and distribution;
  • Wayland or X11, desktop/compositor and graphics driver;
  • the steps that reproduce the issue and what you expected to happen;
  • the terminal output or exact error message;
  • whether it also happens in a new profile and with extensions disabled.

For interface freezes, include the entries from Settings › About › Responsiveness or ~/.cache/oynix/PROFILE/freezes.log. Please remove personal URLs, tokens and other private information before posting logs to an issue.

Report a problem on GitHub and include the information above.
