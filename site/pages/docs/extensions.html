Built in

Three extensions come with OyNIx, in the same .oynix format as any other. They’re listed under Settings › Extensions, where each can be turned off.

ExtensionWhat it does
ScraperA toolbar panel that collects the page’s text (with headings and lists kept), images, links and tables, and copies or saves them as text, JSON or CSV. Its Read text from pixels buttons read the visible page, an area you drag over, or every picture and canvas, for pages where the words aren’t text: scans, canvas apps, signs in photos.
Firefox Add-ons ButtonThe Add to OyNIx button on addons.mozilla.org.
GraphiteA quiet, nearly monochrome style for the browser with squarer corners. Choose it in Settings › Appearance › Browser Style.

From the Extension Gallery

Open the Extension Gallery in OyNIx and click Add to OyNIx. The browser asks before installing. In other browsers the button downloads the package instead; install it with oynix --install-extension, or open the downloaded file in OyNIx.

From addons.mozilla.org

Open any add-on on addons.mozilla.org. Mozilla shows its own install button only to Firefox, so OyNIx adds an Add to OyNIx button in the bottom corner of the page. It fetches the add-on’s current version and asks before installing.

Firefox extensions are adapted on install: Firefox-only manifest keys are removed, background scripts become a service worker on Manifest V3, and browser.* calls return promises as Firefox’s do.

From a file or folder

Settings › Extensions › From File… takes .crx, .xpi, .zip and .oynix files; From Folder… loads an unpacked extension, which is handy while you write one. Opening any .xpi, .crx or .oynix link in OyNIx also offers to install it. From a terminal:

oynix --install-extension ublock_origin.xpi --install-extension ./my-extension
oynix --list-extensions

Manifest V2 and V3 both work. Each extension can be turned off or removed in Settings › Extensions; if one fails to load, the reason is shown there.

Manifest V2

Chromium, which OyNIx uses through Qt WebEngine, no longer loads Manifest V2 extensions. OyNIx still runs them: on install it rewrites the manifest into the V3 form Chromium accepts (actions, host permissions, web-accessible resources, shortcuts), runs the extension’s background page itself as a persistent page, as V2 expects, and provides the V2 APIs such as chrome.extension, tabs.executeScript, browserAction and pageAction. Settings shows these extensions as MV2.

Two V2 behaviours can’t be reproduced. webRequest listeners marked "blocking" are called, but their answers can’t cancel or change requests, because Qt WebEngine decides each request before an extension could reply. And a popup’s getBackgroundPage() can’t hand back the background page’s live window, which lives in another process. Use messaging instead.

Powerful APIs

Some APIs let an extension act outside the pages you visit. They’re off until you turn on Settings › Extensions › Developer mode and then Allow powerful extension APIs, and even then only extensions that ask for them in their manifest get them:

APIWhat it allows
nativeMessagingStarting a program on your computer and talking to it, as password managers such as KeePassXC-Browser do. OyNIx finds native hosts installed for Chrome, Chromium, Brave, Vivaldi, Edge, Firefox or OyNIx (~/.config/oynix/NativeMessagingHosts), and only starts a host whose manifest lists the extension.
cookiesReading and changing every cookie, including sign-ins.
webRequestSeeing every request the browser makes, with its headers.
browsingDataDeleting history, cookies, cache and downloads.
managementListing other extensions, turning them on or off, and removing them.

Extensions installed from a .crx keep the ID they have in the Chrome Web Store, so native hosts that list that ID work unchanged.

What doesn’t

Blocking webRequest, declarativeNetRequest, proxy, debugger, devtools panels, identity.getAuthToken and Firefox sidebars aren’t available. Calls to them fail with a clear error rather than crashing the extension. Network ad blockers such as uBlock Origin still hide page elements and work in their popup, but OyNIx’s built-in blocker does the request blocking.
