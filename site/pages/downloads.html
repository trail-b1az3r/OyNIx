git clone {{repo}}.git && cd OyNIx
./scripts/deps-ubuntu.sh      # system libraries, Rust and Qt 6.12
cargo build --release
./scripts/install.sh          # into ~/.local, with a desktop entry

Every release lists SHA-256 checksums. Download SHA256SUMS alongside a package and check it with sha256sum -c SHA256SUMS.
